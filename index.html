Pick a cell

Look at every column. Some problems are loud (a number that cannot exist). Some are quiet (the same thing written two ways, or a row you have already seen).

How to decide
  1. Is the column numbers or words?
  2. Numbers: does another unit or scale make the value sensible? Yes → measurement error. No → capture error.
  3. Words: does the same spelling repeat, and can you still tell which category it means? Yes → coding inconsistency. No → capture error.
  4. Empty or a code for "no answer" → missing value. The whole row seen before → duplicate row.
Missing valueNothing was answered: a blank cell, or a code such as 999, ? or N/A.
Capture errorA slip while typing: a wrong digit or decimal point, text typed into a number column, or a one-off misspelling.
Measurement errorTyped correctly, wrong unit or scale: minutes instead of hours, 0–10 instead of 0–100.
Coding inconsistencyOne category written in several forms (Economics / Econ / economics). Each form repeats and is still recognisable.
Duplicate rowThe whole row appears twice: same person, same week, same values.
